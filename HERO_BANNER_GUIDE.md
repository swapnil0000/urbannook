# How to add a homepage banner

1. Open the admin panel → **Operations Hub → Hero banner**.
2. Click **Add slide** (max 6).
3. Upload the **desktop** image (best **1920×800**, WebP, under 350 KB) and, if you have it, the **mobile** image
   (best **1080×1350**, WebP, under 250 KB). The mobile image is its own artwork, not a crop. Without one, phones show the desktop image.
   Other shapes work too (for example 3:2 desktop, 2:3 mobile): the picture is shown whole, never cropped, and the banner takes
   its shape (desktop height is capped at 720 px / 85% of the screen; the sides then fill with the artwork's own colour).
   The form only refuses absurd shapes (desktop 1.2:1–3.2:1, mobile 0.5:1–1:1), files that are too small or too heavy,
   and warns when a file is above the size target or not the best shape.
4. Write the **alt text** (what the banner says, e.g. "Diwali Special Sale, 1 to 7 November"). Required.
5. Optional: **link** (`/products?...` or `https://...`) and **show from / hide after** (IST) to schedule the slide.
6. Use the up/down arrows to set the order, tick **Enabled**, then **Save hero banner**. It is live within about a minute.

What shoppers see: no live slide → the usual hero; one live slide → a static banner; two or more → a slideshow
(swipe on phones, arrows on desktop). Autoplay and seconds per slide (3–10) are set at the top of the page.

Tips: use the same shape for every slide in one slideshow (the tallest slide sets the height). Keep the headline and the "Shop Now" button in the middle of the picture; convert to WebP before uploading
(e.g. squoosh.app, quality 75–80, sRGB). To replace an image, remove it in the slide and upload the new one.
